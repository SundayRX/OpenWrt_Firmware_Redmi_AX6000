## 首次使用

1. 有线接入 LAN，在浏览器打开 `192.168.31.1`，以 `root` 登录并设置管理密码；首次启动未预设密码。
2. 设置 WAN 上网方式、Wi-Fi 名称与密码。默认主机名为 `Redmi_AX6000`，时区为 `Asia/Singapore`（UTC+8），LAN IPv6 默认关闭。
3. 在“网络 → DHCP/DNS → 静态租约”管理固定地址，离线设备的记录也会保留。ARP 绑定只固定 IP 与 MAC 的邻居映射，不负责给设备分配地址。
4. 上传、下载文件可使用网页文件传输，或通过现有 SSH 服务使用 SFTP。SFTP 沿用 SSH 的端口和登录认证；SSH 默认端口为 `22`，修改过设置的设备使用自己的端口。
5. 基础上网正常后再配置扩展服务。OpenClash 需要下载代理核心、导入自己的配置并启用。

这些默认值适用于未保留配置的首次启动；保留配置更新会继续使用兼容的原有设置。

## 更新与回退

| 使用场景 | 文件与操作 |
|---|---|
| 系统内更新 | 在“系统 → 备份/升级”上传普通 110m 的 `*squashfs-sysupgrade.bin`。同系列且配置兼容时可保留设置，回退旧版建议清空。 |
| 跨系列切换 | 升级或回退都取消保留配置，重新设置网络和安装兼容插件，不整包恢复另一系列的备份。 |
| U-Boot 安装或恢复 | 使用同包 `*squashfs-factory.bin`；多布局引导选择 `immortalwrt-110m`，不要选择 `default`。 |
| 首次安装或更新引导 | 使用 RB06 普通 110m 配套 `bootloader/mt7986_redmi_ax6000-fip-fixed-parts.bin`，并按该发行文件清单确认附件。日常系统更新无需重刷 FIP。 |

三条系统线使用相同的普通 110m 配套引导，无需先安装 21.02。FIP 负责启动，系统内容由 factory/sysupgrade 镜像提供。原厂设备先解锁、备份本机分区，再按[首次安装步骤](flashing.md#原厂首次安装)准备引导；FIP 不用于 LuCI 系统升级页面。

跨系列时能否自动禁止保留配置，取决于当前运行的固件。旧系统没有提示时仍须手动取消；镜像检查不通过时，先核对设备、文件和布局，再按[旧版处理与恢复步骤](flashing.md#配置与插件怎么恢复)操作，不勾选强制升级。

升级前保存配置、上网参数和独立插件数据。外装插件程序通常需要重新安装，完整流程见[安装、升级与恢复](flashing.md)。

## 使用须知

- 第三方插件须兼容 FW4 / nftables 和 IPK 格式。内核模块还须匹配本固件的内核版本及 ABI，CPU 架构相同并不足够。
- 硬件加速、透明代理与软件限速可能相互影响，加速流量的统计也可能不完整。启用限制后检查实际访问和限速结果。
- 使用 MediaTek HNAT 时，需要同时选择对应的“快速转发引擎”并启用硬件加速；IPv6 加速选项只控制 IPv6 硬件转发。保存后通过页面运行状态确认结果。
- 透明代理接管的流量不一定受上网时段控制。需要按时段完整断网时，先停用相关透明代理，再检查实际效果。
- 信道分析用于观察周边网络，不会自动选择或更改工作信道。扫描会短暂占用无线资源，结果不保证包含所有邻居网络。
- 无线驱动与芯片固件随完整系统配套更新，不从其他系统混装无线内核模块。

反馈时提供固件完整版本、安装方式和复现步骤，见[反馈说明](../README.md#反馈)。
