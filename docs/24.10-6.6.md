## 与 padavanonly 原版的区别

本系列基于 [padavanonly/immortalwrt-mt798x-6.6](https://github.com/padavanonly/immortalwrt-mt798x-6.6)，针对 Redmi AX6000 的普通 110m 布局与日常管理需求进行适配。

| 方面 | 本系列提供的功能 |
|---|---|
| 普通 110m 安装与升级 | 配套 hanwckf 普通 110m 引导，提供本机型的系统镜像、网络端口配置和网页升级支持 |
| 无线管理 | 完善无线开关、MU-MIMO 和多个 Wi-Fi 网络的设置与应用 |
| 常用插件 | 适配 FW4 下的上网时段控制、文件传输、NTP 校时、UU 加速、TurboACC 和 MTK QoS |
| 加速与限速配合 | 按时段控制和限速需求暂停硬件加速；相关限制解除后恢复原有设置 |
| 管理界面 | 使用 Argon 主题，统一统计菜单，完善中英文提示、系统状态和版本显示 |

MTK 厂商无线驱动、无线固件、WARP 及系统基础沿用 padavanonly 整合的成果，保留各组件的来源与许可。完整来源见[来源与许可](sources-and-licenses.md)。

## 首次使用

管理地址为 `192.168.31.1`，用户名 `root`，未预设密码。首次登录后设置管理密码，再配置上网和 Wi-Fi；时区与 IPv6 等默认项见[首页](../README.md#默认设置)。保留配置升级沿用已有设置，包括手动开启的 LAN IPv6。

## 常用管理功能

具体预装内容和软件版本见发行说明及 ZIP 内的 `packages.txt`。预装服务仍需按需配置和启用。

| 功能 | 用途与条件 |
|---|---|
| 上网时段控制 | 按设备和路由器本地时间设置上网时段，支持跨午夜；严格模式暂停硬件加速 |
| 文件传输 | 在管理页面上传、下载、删除文件及安装匹配系统的 IPK |
| NTP 校时 | 启用后接管校时，停用时恢复此前的系统校时服务；插件默认关闭 |
| UU 游戏加速器 | 配置、启动和查看 UU 服务；默认关闭 |
| TurboACC 网络加速 | 管理 MTK 硬件加速、FW4 全锥 NAT 和 TCP 参数 |
| MTK QoS | 提供设备限速、硬件公平队列及 IPv4 多 WAN 分流 |

此外提供 Wi-Fi 管理、ARP 绑定、定时重启、DDNS、流量统计、系统监控、网页终端、UPnP、OpenClash 和 KMS 等功能，以所下载版本为准。

## 插件搭配与使用须知

- **插件兼容性：** 选择支持 FW4 / nftables 的 IPK。21.02 的防火墙规则、无线驱动及内核模块不能直接移入本系统。
- **上网时段控制：** 透明代理可能影响控制效果。需要按时段完整断网时，先停用相关代理，再检查访问结果。
- **设备限速与统计：** 软件限速会暂停硬件加速；多个功能都要求暂停时，停止其中一个不会立即恢复。硬件加速也可能影响流量统计。
- **OpenClash：** 首次使用需下载代理核心并导入自己的配置。
- **独立插件：** ProxyFence 和 WOLink 程序不预装。ProxyFence 应使用 FW4 安装包；启用前停用 OpenClash、硬件加速与流量卸载，其 IPv4 规则不覆盖 IPv6。WOLink 的身份与配对数据需单独备份。

## 安装、更新与回退

<a id="适用设备与下载文件"></a>

**本系列只提供普通 110m 固件。** 下载包不附 BL / FIP 引导，要求设备已有匹配的普通 110m 分区和引导。安装前阅读[布局要求](flashing.md#layout-comparison)，并按[安装指南](flashing.md#verify-download)校验文件。

已有本仓库固件且管理页面可用时，从“系统 → 备份/升级”上传目标版本的 `*squashfs-sysupgrade.bin`，无需重刷 U-Boot。从 21.02 升级到本系列，或回退到 21.02，**两个方向都取消保留配置**，重新设置网络和 Wi-Fi，再安装兼容插件。

同系列更新可按发行说明保留配置，回退旧版建议清空配置。完整备份仅用于恢复对应系统，不整包导入另一系列。操作步骤见[网页更新与回退](flashing.md#web-upgrade)；系统无法启动时，见[恢复指南](flashing.md#u-boot-恢复与布局边界)。
