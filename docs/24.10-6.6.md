## 适用设备与下载文件

仅支持 **Redmi AX6000 / RB06 + 普通 `immortalwrt-110m` 布局**。下载包不包含 BL / FIP 引导，升级使用设备上已有且匹配的引导。stock、`ubootmod`、小米 AX6000 / RA72 及其他机型不在本系列范围内。

当前使用 stock 的设备，先阅读 [110m 与 stock 布局对比](flashing.md#layout-comparison)并确认布局迁移方案，完成普通 110m 适配后再安装本系列固件。

先从 Release 正文已完成的构建入口下载 ZIP 与同构建标识的 `SHA256SUMS-构建标识.txt`；外层的 `packages-构建标识.txt` 和 `build-info-构建标识.json` 也对应这一组文件。校验并解压后，在 `firmware/` 中选择镜像：日常系统内升级使用 `*squashfs-sysupgrade.bin`；`*squashfs-factory.bin` 供匹配的安装入口使用。factory 文件不能直接从小米原厂网页安装，也不需要在 sysupgrade 前额外刷一次。ZIP 内仍使用 `packages.txt`、`build-info.json`、`release-notes.md` 和 `SHA256SUMS`，分别保存该次预装包、配置、说明和校验信息。

## 已适配的管理功能

下表说明本系列对这些功能的适配内容；**是否预装请查看该次构建说明和 ZIP 内的 `packages.txt`**。主要服务控制由本项目的 Go 后端承担，无线配置仍沿用并修正现有的 Shell / Lua 管理程序。

| 功能 | 在本系列中的使用方式 |
|---|---|
| 上网时段控制 | 按设备和本地时间设置上网时段，支持跨午夜规则；使用 nftables 管理转发限制。未设置有效规则时不产生限制。严格模式会暂停硬件加速。 |
| 文件传输 | 在已登录的管理页面上传、下载、删除文件及安装 IPK，补齐路径检查和上传失败处理；安装软件仍需满足 OPKG 的依赖要求。 |
| NTP 校时 | 启用插件后管理校时进程，并协调系统原有的时间服务；停用时恢复此前的系统校时状态。默认不启用该插件。 |
| UU 游戏加速器 | 适配配置、启动和状态管理，实际加速仍由原有 UU 程序提供。服务默认关闭，需要自行配置并确认服务可用。 |
| TurboACC 网络加速 | 管理 MTK 硬件加速、FW4 fullcone 和 TCP 参数，并显示运行状态；不保留旧版 SFE / fast-classifier 开关。 |
| MTK QoS | 适配设备限速、硬件公平队列及 IPv4 多 WAN 分流，管理相应的 nftables、路由与限速规则，并处理停用清理和恢复。 |

使用上网控制和限速时，请留意以下限制：

- 严格上网控制针对转发流量，OpenClash 等透明代理可能改变流量路径。需要按时段完整断网时，先停用相关透明代理，再验证实际访问结果。
- 软件限速会暂停硬件加速；当多个功能需要暂停加速时，停止其中一个功能不代表立即恢复加速。硬件公平队列最多覆盖 31 个客户端，超出其数量或速率能力时改用软件处理，实际吞吐须在自己的网络中验证。
- 硬件加速可能影响流量统计可见性。限速生效、统计准确性、加速命中和最大吞吐是不同项目，请以该次构建的实机结果为准。

## 无线与独立插件

无线使用 MTK 厂商配套，驱动包标记为 **7.6.6.1**，无线固件来源标识为 `mt7986-asus-ax6000`。该标识表示所采用的固件来源，并不改变 Redmi AX6000 的设备身份。驱动、无线固件和 WARP 需要成套使用，不要根据版本数字与 21.02 系列的 7.6.7.x 简单排序，或单独互换组件。

FW4 使用 nftables。安装独立 IPK 时核对系统版本、架构及防火墙依赖；FW3 / iptables 的旧插件、规则和内核模块不能直接沿用。

- **OpenClash**：含有管理界面和依赖的固件仍需首次下载代理核心，并导入自己的配置。
- **ProxyFence**：程序本体不预装，使用其适配 FW4 的安装包。与 OpenClash 按需互斥启用；开启围栏前先停用 OpenClash、硬件加速和流量卸载，并按插件检查确认旧规则与卸载连接已清理。本固件没有自动互斥开关。
- **WOLink**：程序本体不预装。重新安装或升级前单独备份插件的完整身份与配对数据；系统保留配置不代表外装程序及其全部数据都会保留。

准备好运行依赖不等于独立插件已经完成当前固件的整套实机验证。ProxyFence 的 IPv4 规则也不能作为 IPv6 流量已受同样控制的依据。

## 默认设置与其他功能

默认管理地址 `192.168.31.1`、主机名 `Redmi_AX6000`、用户名 `root`、新加坡 UTC+8，未预设管理密码。首次登录请设置密码；所下载构建有不同默认值时以该次说明为准。保留配置升级沿用原设置。

除上述功能外，固件还可包含 ARP 绑定、定时重启、DDNS、流量统计、系统监控、网页终端、UPnP 和 KMS。请在该次构建说明和 ZIP 内的 `packages.txt` 中确认实际预装内容。

## 从旧版迁移

首次从 21.02 / FW3 切换到本系列，确认设备已使用匹配的普通 110m 布局后，**取消保留配置**并重新设置网络与 Wi-Fi。把旧系统完整备份留作回退；新版按项目逐项恢复必要数据，不直接恢复整份旧网络、防火墙或无线驱动配置。

后续在本系列内、同一布局的升级可以使用 LuCI / SSH 的保留配置流程。保留设置不等于保留外装程序，独立插件仍需核对并重新安装。U-Boot 网页写入会重建用户数据区。步骤见[安装、升级与恢复](flashing.md)。
