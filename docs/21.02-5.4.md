**适用于 Redmi AX6000 / RB06、普通 110m 布局。** 本系列使用 FW3 / iptables，OPKG / IPK，提供 Argon 2.3.1 管理界面。

## 首次使用

1. 有线接入 LAN，打开 `192.168.31.1`，以 `root` 登录并设置管理密码；未预设密码。
2. 配置 WAN 上网方式、Wi-Fi 名称与密码。默认主机名 `Redmi_AX6000`、时区 `Asia/Singapore`（UTC+8）、LAN IPv6 关闭，实际以发行说明为准。
3. 需要固定设备地址时，在“网络 → DHCP/DNS → 静态租约”查看和编辑，离线设备也会保留记录。ARP 绑定用于静态邻居映射，不替代 DHCP 分配地址。
4. 确认基础上网后再启用插件。OpenClash 需下载代理核心并导入自己的配置；安装第三方 IPK 前核对系统、防火墙与依赖。

以上是无配置首次启动的设置；保留配置更新继续使用兼容的原有设置。

## 更新与回退

- **系统内更新：** 使用普通 110m 的 `*squashfs-sysupgrade.bin`，在“系统 → 备份/升级”上传。同系列且配置兼容时可保留设置，回退旧版建议清空。
- **跨系列切换：** 与其他系列之间升级或回退都取消保留配置，重新设置网络和安装兼容插件，不整包恢复另一系列的备份。
- **U-Boot 安装或恢复：** 使用同包 `*squashfs-factory.bin`，多布局引导明确选择 `immortalwrt-110m`；`default` 不是本固件使用的布局。
- **引导文件：** RB06 普通 110m 配套 FIP 的路径为 `bootloader/mt7986_redmi_ax6000-fip-fixed-parts.bin`，用于首次安装或明确需要更新引导的情况。下载时按该发行的文件清单确认是否附带；日常系统更新无需重刷。

配套引导适用于三个系列，无需先安装 21.02。FIP 负责引导，系统修复由 factory/sysupgrade 镜像提供。原厂设备仍须先解锁、备份本机分区并按[首次安装步骤](flashing.md#原厂首次安装)准备引导；不要把 FIP 上传到 LuCI 系统升级页面。历史下载包以原文件清单为准。

自动禁止保留配置取决于**当前运行的固件**；没有自动提示时仍须手动取消。镜像检查不通过时，核对文件与布局后按[旧版处理与恢复步骤](flashing.md#配置与插件怎么恢复)操作，不勾选强制升级。

升级前保存配置、上网参数和独立插件数据。外装插件程序通常需要重装；完整步骤见[安装、升级与恢复](flashing.md)。

## 使用须知

- 插件须匹配 FW3 / iptables 和 IPK 格式。内核模块还必须匹配本固件的内核版本及 ABI，不能只看 CPU 架构相同就安装。
- 硬件加速、透明代理与软件限速可能相互影响，流量统计也可能不完整。启用限制后检查实际访问和限速结果。
- 信道分析用于查看周边网络，不自动选择或更改工作信道。扫描短暂占用无线资源，图表不保证列出所有邻居网络。
- `r0-3700024` 的信道分析可能无法正常绘图；后续修复及适用版本见上表。
- 无线驱动与芯片固件随完整系统配套更新，不从其他系统混装内核模块。
- 本系列信道图不完整展示邻居的 80/160 MHz 带宽，不据此判断本机无线的工作带宽。
- 已公开的 `r0-3700024` 可能因权限判断错误无法打开文件传输页面，修复及适用版本见“后续更新（尚未公开）”。需要传输文件时，可使用已配置好的 SSH/SFTP；安装 IPK 可使用“系统 → 软件包”。

反馈时提供固件完整版本、安装方式和复现步骤，见[反馈说明](../README.md#反馈)。
