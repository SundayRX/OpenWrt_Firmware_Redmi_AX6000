防火墙、软件包和 Wi-Fi 管理是基础功能。其他预装软件及具体版本请查看发行说明和 ZIP 内的 `packages.txt`。

## 首次使用

管理地址为 `192.168.31.1`，用户名 `root`，未预设密码。首次登录后先设置管理密码，再配置 WAN 和 Wi-Fi；时区与 IPv6 等默认项见[首页](../README.md#默认设置)。保留配置升级后继续使用已有设置。

预装服务需要按需配置和启用。OpenClash 首次使用需下载代理核心；独立安装的 IPK 应匹配本系统的架构与 FW3 / iptables 依赖。ProxyFence、WOLink 程序不随固件预装。

## 安装、更新与回退

**本系列公开下载只提供普通 110m 固件**，布局标识为 `immortalwrt-110m`。安装前请确认设备已具备匹配的分区和引导，见[布局要求](flashing.md#layout-comparison)。

日常更新使用 ZIP 内的 `*squashfs-sysupgrade.bin`，从“系统 → 备份/升级”上传。同系列更新可按发行说明保留配置；回退旧版建议清空配置。

下载包同时附带普通 110m 配套 FIP 引导，来源为 [hanwckf/bl-mt798x](https://github.com/hanwckf/bl-mt798x)。**日常系统更新无需重刷引导。** factory 镜像供匹配的安装或恢复入口使用，无需与 sysupgrade 依次刷入。文件用途和校验方法见[安装指南](flashing.md#verify-download)。

切换到 [24.10 / 6.6](24.10-6.6.md) 或从该系列回退时，**两个方向都取消保留配置**，再重新设置网络和 Wi-Fi；不整包恢复另一系列的配置。完整步骤见[网页更新与回退](flashing.md#web-upgrade)。

## 使用须知

- 硬件加速、代理与设备限速可能影响彼此的效果，也可能影响流量统计。按实际需要启用，并检查限速和统计结果。
- 无线驱动、无线固件和加速组件随固件配套提供，不单独混装其他系统的内核模块。
- 每次发行的功能、改进和已知限制以该 Release 的说明为准。遇到问题时，请按[反馈说明](../README.md#反馈)提供版本信息。
